# 10｜動手練習與檢核答案

先自己回答，再看後半部參考答案。

## 練習 A：畫 trajectory

情境：使用者上傳 DICOM，問「是否有肺積水？」模型需要先轉檔，再分類與分割，最後回答。

請畫出每一輪的 AIMessage、ToolMessage 與 node。

## 練習 B：找控制權

判斷以下限制屬於 prompt 還是 code：

1. 工具輸出互相衝突時要解釋。
2. AIMessage 有 tool call 時一定進 ToolNode。
3. 最終只能輸出一個 boxed option。
4. 只載入 `tools_to_use` 指定的工具。
5. 不能提供 treatment plan。

## 練習 C：找 naming bug

比較 `main.py` 的 default selected tools 和 `all_tools` registry，說明為何某個 VQA tool 可能沒有載入，以及如何讓初始化 fail fast。

## 練習 D：設計 bounded loop

在不改 tool implementations 的前提下，替核心 state 增加：

- `agent_steps`；
- `tool_call_counts`；
- `started_at`；
- `termination_reason`。

說明檢查應放在 model 前、tool 前或 tool 後。

## 練習 E：RAG trust boundary

解釋為什麼 `RAGTool` 回傳 `source_documents`，仍不能保證 final answer grounded。

## 練習 F：TFDA 轉譯

設計三個只讀 tool，並標示每個 tool 的：

- input schema；
- result schema；
- candidate evidence；
- policy level；
- call limit。

## 參考答案

### A：合理 trajectory

```text
agent
→ AIMessage(tool_call=dicom_processor)
tools
→ ToolMessage(output_png_path)
agent
→ AIMessage(tool_calls=[classifier(output_png), segmentation(output_png)])
tools
→ ToolMessage(classification)
→ ToolMessage(segmentation)
agent
→ AIMessage(final text, no tool_calls)
END
```

DICOM 與下游工具不可在第一輪平行，因為下游 input path 尚未產生。

### B：答案

| 項目 | 類型 |
| --- | --- |
| 衝突時解釋 | prompt |
| 有 tool call 進 ToolNode | code |
| 單一 boxed option | prompt |
| selective initialization | code |
| 不提供 treatment plan | prompt |

### C：答案

default 是 `XRayVQATool`，registry 是 `CheXagentXRayVQATool`。loop 對 unknown key 沒有 else/raise，所以安靜跳過。改善方式：先驗證 `requested - available`，非空時 raise，或在非 strict mode 回傳 structured skipped list。

### D：建議位置

```text
model 前：wall-clock、max agent steps、token/cost budget
tool 前：tool allowlist、args、per-tool call count、approval、cache
tool 後：latency、result status、domain validation、cost accumulation
```

不能只在 prompt 叫模型自行計數。

### E：答案

因為至少有兩次生成：RAG 內層 RetrievalQA 先生成 answer，外層 orchestrator 再生成 final text。兩層都可能省略、誤解或新增 claim；核心沒有程式化 claim-source mapping verifier。

### F：示例

| Tool | Input | Output | Policy | Limit |
| --- | --- | --- | --- | --- |
| `search_tfda_risk` | query, top_k | ranked candidate evidence | READ_ONLY | 2 |
| `lookup_license` | ingredient/name | license metadata candidates | READ_ONLY | 2 |
| `compare_evidence` | evidence IDs | conflict/missing-field report | READ_ONLY | 1 |

三者都不能產生可直接交付的醫療答案；結果必須進 B。
