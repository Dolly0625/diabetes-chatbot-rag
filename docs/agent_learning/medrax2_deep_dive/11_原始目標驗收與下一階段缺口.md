# 原始目標驗收與下一階段缺口

這一章不是新增技術，而是回到最初要求，避免做了很多程式與測試後，反而忘記真正要完成什麼。

## 一、原始目標

原始要求可以拆成兩個主目標：

1. 撰寫很詳細、可分成多檔案的 MedRAX2 agent 設計閱讀文件，帶入重要程式碼，方便學習，並自行檢查修改。
2. 完成文件後，在額外資料夾開始嘗試把目前 TFDA 糖尿病主題專案提升到 MedRAX2-style agent 的工程等級，不能先混入現有專案。

第二項的動詞是「開始嘗試」，所以驗收時必須區分：

- 是否已建立一個有代表性的可執行架構實驗；
- 是否已完整達到 MedRAX2 的產品能力與工具廣度。

這兩件事不能混為一談。

## 三、這次真正達到的層級

這一輪達到的是 **agent harness architecture spike**：

```text
固定安全外骨架
        │
        ▼
動態 agent ↔ tools 內迴圈
        │
        ▼
證據與輸出強制驗證
```

它已足以用來學習以下工程問題：

- 誰能決定下一個工具；
- 誰能阻止未允許的工具；
- tool result 如何進入 state；
- 候選證據如何與核准證據分離；
- 如何終止失控迴圈；
- 如何保存 thread memory，又分離單次 run trace；
- 如何在不依賴外部 LLM 的情況下測 orchestration。

它尚不足以證明：

- retrieval 品質已達正式 RAG 水準；
- agent 能回答廣泛醫療問題；
- 真實 LLM 一定會穩定選對工具；
- 系統已具備臨床安全性；
- API、UI、身份驗證、持久化與高併發已可上線。

## 四、隔離是否真的成立

目前隔離實驗只有一個對既有專案的依賴：

```text
tfda_medrax2_experiment
        │
        └── read-only
              │
              ▼
tfda_context_gate/data/processed/langchain_documents.json
```

它沒有：

- `from tfda_context_gate ...`
- `import tfda_context_gate`
- 修改既有 graph、router、gate 或 retriever
- 把實驗 entrypoint 接到現有服務

因此可以安全比較兩種架構。若實驗失敗，可以整個停用該資料夾，而不影響原專案。

## 五、回頭檢查時發現的偏差

第一次真實 demo 曾因 query 中的共同詞「抑制劑」把 JAK/CDK 文件列為候選。這代表：

1. graph 能跑完，不等於 retrieval 正確；
2. 來源正確，不等於 evidence 與問題相關；
3. 測 fixture 通過，不等於真實 corpus 通過。

目前已加入 Latin drug-class anchor 與真實 129 筆 corpus regression test。但這只是修正已知案例，不能取代完整 retrieval benchmark。

## 六、下一階段不能偏離的三個目標

如果繼續開發，優先順序應是：

1. **讓證據選擇可量測**：建立 TFDA 糖尿病問題集、gold evidence、Recall@K、citation validity 與錯誤分類。
2. **接上真實模型但維持可重現**：加入 tool-calling LLM integration，保存去識別 fixture，測 tool selection、loop termination 與輸出閘門。
3. **補產品外殼而不破壞安全骨架**：再加入 FastAPI/streaming、persistent checkpoint、監控與 UI；不能為了展示效果繞過 A/B/D。

多模態工具只有在 TFDA 主題真的需要藥袋、仿單或圖片輸入時才加入。不能為了表面上像 MedRAX2，就搬入和研究題目無關的影像工具。

## 七、下一輪的 Definition of Done

下一輪如果宣稱「更接近 MedRAX2 等級」，至少要提出下列證據：

- 一組版本固定的 TFDA 評測題目與 gold evidence；
- baseline 與新 retrieval 的定量比較；
- 真實 tool-calling model 的錄製 trace；
- allowlist、loop limit、timeout、錯誤正規化與 citation gate 測試；
- 相同 query 多次執行的穩定度；
- API 層不會跳過 graph gate 的 integration test；
- 清楚列出仍未達成的臨床與產品限制。

在這些條件完成以前，正確說法仍是「TFDA MedRAX2-style 隔離架構實驗」，不是「已完成的 MedRAX2 等級醫療 agent」。
