03 · 為什麼這樣設計

四個決定，對應四種風險。

1

Agent 與 Gate 分離

Planner 可以規劃下一步，但不能跳過 A、B、D 或自行批准自己的證據。

2

圖片先確認再匹配

OCR 只是候選 observation；原圖對照與使用者確認後，才允許藥品／許可證唯一匹配。

3

工具受程式控管

Tool Executor 限制工具、參數、權限、逾時與成本，工具不得直接生成醫療結論。

4

分期驗證新增能力

先驗證文字三流程，再依效益／風險決定多工具、圖像、長程狀態與多 Agent 是否投入。

核心原則：讓 Agent 保有彈性，但讓固定規則保有最後控制權。
