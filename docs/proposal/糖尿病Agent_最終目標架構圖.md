## 固定權責

- Planner／Agent 可以提出下一步，但不能跳過 A、B、D。
- Tool 只產生 observation 或 candidate evidence，不能直接產生正式醫療結論。
- 處方／藥袋 OCR 只是待確認 observation；必須經使用者確認與唯一藥品匹配，不能靠外觀或近似名稱猜藥。
- Boundary Supervisor 只能標記問題及要求審查，不能用 Agent 共識取代證據批准。
- 診斷、處方、停換藥與劑量調整不屬於本架構的自主輸出範圍。
